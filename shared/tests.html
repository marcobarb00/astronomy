Each case is a worked example from J. Meeus, Astronomical Algorithms (2nd ed., 1998), a value from the SOFA / ERFA test suite, a position from JPL Horizons (DE441), or an internal consistency check. The tolerance of each ephemeris case is the accuracy documented in the header of ephemeris.js: the reference sky uses Standish's Keplerian elements, so it is not expected to match Meeus' full VSOP87 results to the arcsecond.
